# ModerationBot

ModerationBot is a Minecraft plugin designed to enhance server moderation with features like raid mode, suspicious account detection, spam message removal, and ticket management. It includes automatic verification for new members, configurable commands, and robust logging to ensure server security and efficiency.

## Install

1. Download the latest release from the GitHub repository.
2. Place the JAR file in your server's `plugins` directory.
3. Restart your server to load the plugin.

## Use

1. **Raid Mode**:
   - Enable raid mode with `/raid on`.
   - Configure raid settings with `/raid config`.
   - Disable raid mode with `/raid off`.

2. **New Member Verification**:
   - Set up verification with `/raid config`.
   - New members will receive a verification message.

3. **Ticket System**:
   - Create a ticket panel with `/ticket panel`.
   - Configure ticket categories and settings.
   - Manage tickets using the provided buttons.

4. **Logging**:
   - All actions are logged in the specified log channel.
   - View logs with `/raid logs` or `/ticket stats`.
